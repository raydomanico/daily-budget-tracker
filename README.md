# Daily Budget Tracker

A personal daily budget tracking web app built with vanilla HTML, CSS, and JavaScript.

## Features
- Track daily budget with a set spending limit
- Deposit and spend across multiple accounts (Salary, Savings, Others)
- Transaction history that persists across sessions
- Negative balance protection
- Success and error notifications
- Daily budget reset with automatic savings transfer

## Tech Stack
- HTML
- CSS (Flexbox, CSS Variables)
- JavaScript (DOM manipulation, localStorage)

## What I Learned
- State management with a plain JavaScript object
- Persisting data with localStorage and JSON
- DRY code principles using reusable functions
- Responsive UI design inspired by fintech apps like Maya
